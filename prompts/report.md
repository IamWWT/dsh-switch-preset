# 复盘 / 报告指令

```
为 {{项目/周期}} 写一份 {{周报/项目复盘/交付报告}}：

1. 依据 docs/04-progress/、docs/05-testing/、docs/06-experience/ 的真实记录
2. 包含：完成内容（指到证据）、失败与教训（诚实）、未完成与原因、下一步
3. 报告写入 docs/06-experience/ 或 docs/07-ops/，并更新 FILE_INDEX
4. 禁止编造数据；没有证据的写"未验证"
```

示例：

```
写本周开发复盘：项目进展、踩坑经验（docs/06-experience/ 有记录）、下周计划。
诚实一点，包括失败的尝试。
```
