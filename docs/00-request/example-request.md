# 示例：一句话需求 → 需求摄入

## 目标项目

| 项 | 内容 |
|----|------|
| 目标项目路径 | `services/shortlink`（相对 cwd） |
| 项目说明 | 高可用短链接服务（Go） |
| 联合开发路径 | （无；如跨项目协作在此列路径与角色：写/参照） |

## 用户原话

> 用 Go 写一个高可用的短链接服务，支持 Redis 缓存和 Prometheus 指标，最好能扛住双十一级别的流量。

## 提炼

| 项 | 内容 |
|----|------|
| 目标 | 短链接生成/跳转服务，高可用、可观测 |
| 用户/场景 | 互联网服务内部与外链分享；峰值流量高 |
| 核心功能（P0） | 创建短链、重定向、自定义别名、过期时间 |
| 次要功能（P1） | 统计点击量、批量创建、删除/停用 |
| 非目标 | 用户注册/登录（P2 再说）、短链分享社交功能 |
| 约束 | Go 语言；Redis 缓存；Prometheus 指标；部署形态未指定 |

## 假设表

| 假设 | 依据 | 影响 |
|------|------|------|
| 存储用 PostgreSQL（非指定） | 默认选择，成熟且与 Redis 配合好 | 若团队已有 MySQL 惯例需替换方言 |
| "双十一级别"按读 QPS 5k/s 设计 | 合理上限，超出需分布式改造 | 架构选型（单实例+缓存 vs 分片） |
| 部署为单个可水平扩展的无状态服务 | 最短路径满足高可用 | 后续可加负载均衡/K8s |
| 鉴权暂不做，短链为公开可访问 | 一句话未提安全上下文 | 上线前必须补管理员 API 鉴权（安全清单） |
| 生产部署需要 API 管理入口鉴权（至少 admin token） | 安全铁律 #1/#2 | 加入 P0 实现 |

## 澄清问题（仅当阻塞时）

1. 数据库有既定选型吗（PostgreSQL/MySQL/其他）？
2. 部署环境是什么（K8s/裸机/云函数）？
3. 短链域名和品牌前缀有要求吗？
