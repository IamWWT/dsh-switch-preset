# 00-request — 需求摄入

## 用途

这里保存**用户的原话**和 Agent 的摄入结果。它是整个项目的第一份文档，也是"诚实记录"的起点。

## 文件

- `request.md` — 用户原话（一字不改） + 目标/用户/功能/非目标/约束 提炼 + **假设表** + 澄清问题记录。
- `example-request.md` — 示例（一句话需求如何变成结构化输入）。

## 协议

0. **目标锚定**：Phase 0 即锁定「目标项目路径」（cwd 相对路径）写入 `request.md`；跨项目联合开发时声明「联合开发路径集合」。目标/联合路径之外的写入先经用户确认（防目标漂移，见 project-discipline §0）。
1. 用户发来一句话需求后，Agent 先创建/更新 `request.md`。
2. 原话必须逐字保存（`## 用户原话` 段），后续所有决策可追溯回这句话。
3. 假设表每行格式：`| 假设 | 依据 | 影响 |`。
4. 只有假设会造成不可逆或高风险后果时才向用户提问，一次 ≤ 3 个问题；其余进入 Auto 模式并记录假设。
