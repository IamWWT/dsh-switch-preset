# 04-progress — 诚实进度日志

## 用途

项目生命周期里**每一步**的实际记录：做了什么、验证命令与结果、失败与修复、遗留问题。这是"诚实记录文档"的核心载体。

## 规则

1. 文件名：`YYYY-MM-DD-<主题>.md`（一天多篇用 `-2` 后缀）。
2. 每篇包含：日期、会话/批次、目标、实际动作、验证（命令+结果）、失败与回退、遗留问题、经验链接。
3. **禁止**只写成功：失败、回退、返工必须记录，否则失去"诚实"意义。
4. 追加用 `scripts/journal.sh` 或手动。

## 模板

```markdown
# <YYYY-MM-DD> <批次/主题>

## 目标
（本批要完成什么）

## 实际动作
- （按时间顺序：读/写/验证）

## 验证
```bash
（真实执行的命令）
```
（真实输出摘要 / 结果）

## 失败与回退
- （如实写；没有则写"无"）

## 遗留问题
- （未完成/待确认事项）

## 经验
- （链接到 docs/06-experience/ 或一句话教训）
```
