# 安全规范（红线）

> 原则：**fail-closed**（默认拒绝/关闭），最小权限，防御纵深。不可妥协项标记 ★。

## 1. 凭证与配置 ★

| 规则 | 说明 |
|------|------|
| 源码零硬编码 | 密钥/Token/密码/IP/端口/URL 一律 env 或配置文件注入；源码默认值为空 |
| 凭证不进版本库 | `.env` 进 .gitignore；提供 `.env.example`（值占位或空） |
| 生产默认值安全 | 默认密码/默认密钥=空或强随机；弱默认值启动即失败（fail-fast） |
| 密钥轮换支持 | 密钥可配置、可轮换，不写死 |

## 2. 认证与授权 ★

| 规则 | 说明 |
|------|------|
| 外部入口必须鉴权 | 任何对外 API/Webhook 默认要求认证；无鉴权入口必须 ADR 豁免 |
| 密钥比较用常量时间 | `MessageDigest.isEqual`/`hmac.compare_digest` 等，防时序攻击 |
| 最小权限 | 服务账号只授所需权限；按租户/资源隔离数据 |
| 限流与配额 | 登录/敏感接口限流；防暴力破解 |
| 会话安全 | Token 有过期；登出可吊销；敏感操作二次校验 |

## 3. 输入与输出 ★

| 规则 | 说明 |
|------|------|
| 输入校验 | 所有外部输入校验长度/类型/枚举/范围；拒绝而非清洗 |
| 注入防护 | SQL 用参数绑定；命令执行禁止拼接；路径遍历防护 |
| 输出编码 | HTML/JSON 输出防 XSS；错误信息不泄露内部细节 |
| 反序列化 | 禁止不安全的反序列化；限制类型白名单 |
| 文件上传 | 类型/大小/内容校验，存隔离目录 |

## 4. 传输与依赖

| 规则 | 说明 |
|------|------|
| 传输加密 | 生产环境 TLS；内部敏感链路加密 |
| 依赖漏洞 | 依赖锁定版本；有扫描工具则纳入门禁（如 `pip-audit`/`cargo audit`/`npm audit`/OWASP） |
| 上游可信 | 只用可信源；新依赖先查许可证与维护状态 |

## 5. 审计与隐私

| 规则 | 说明 |
|------|------|
| 关键操作审计 | 登录/授权/删除/状态变更/支付等写审计日志（含 who/what/when/result） |
| 日志脱敏 | 日志禁止打明文凭证/PII；脱敏函数统一 |
| 数据合规 | 涉及个人数据先声明用途与保留期 |

## 6. 验证清单（交付前逐项过）

- [ ] 代码中无硬编码凭证（`rg` 抽查 + 审查）
- [ ] 所有对外入口有认证（或 ADR 豁免声明）
- [ ] 输入校验覆盖所有外部边界
- [ ] 依赖无已知高危漏洞（工具可用时）
- [ ] 错误信息不泄露堆栈/内部路径
- [ ] 审计日志接入关键操作
- [ ] 默认配置 fail-closed（鉴权密钥为空则拒绝启动等）
